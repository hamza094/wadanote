# WadaNote

A platform for creating, acknowledging, and
tracking informal financial agreements and
repayments between people.

## Features

- Create financial agreements
- Borrower acknowledgement
- Agreement revisions
- Witness confirmation
- Partial repayment tracking
- Outstanding balance tracking

## Tech Stack

- Laravel 13
- Vue 3
- Inertia.js
- TypeScript
- Tailwind CSS 4
- shadcn-vue
- MySQL
